# WordPress 101: Build Your Own Website and Online Shop

Welcome to the official workshop repository for **WordPress 101: Build Your Own Website and Online Shop** at **WordCamp Philippines 2026 – Contributor Day**.

This repository contains the workshop files, sample assets, and resources that participants will use during the hands-on workshop.

## Workshop overview

Have you ever wanted to create your own website or launch an online shop, but didn’t know where to start?

This beginner-friendly workshop will guide you through building a complete WordPress website and a simple online shop using **WordPress Studio**, **Storefront**, and **WooCommerce**.

By the end of the workshop, you will have a working WordPress website with a functional online shop running locally on your laptop.

## What you’ll learn

During the workshop, you’ll learn:

* What WordPress is and how it works
* How to navigate the WordPress dashboard
* The difference between pages, posts, themes, and plugins
* How to use the WordPress Block Editor (Gutenberg)
* How to create a homepage and shop page
* How to add products and organize them into categories
* How to build a simple online shop
* How the shopping cart and checkout process works

No coding experience is required.

## What to prepare before the workshop

### 1. Download WordPress Studio

Download and install WordPress Studio before arriving at the workshop.

https://developer.wordpress.com/studio/

WordPress Studio is a free application that allows you to run WordPress locally on your computer, so you can build and practice your website without purchasing hosting or a domain name.

### 2. Download the Storefront theme

Download the latest **Storefront theme ZIP file** from the official WordPress theme directory.

https://wordpress.org/themes/storefront/

Keep the ZIP file in an easy-to-find folder on your laptop.

### 3. Download the WooCommerce plugin

Download the latest **WooCommerce plugin ZIP file** from the official WordPress plugin directory.

https://wordpress.org/plugins/woocommerce/

Keep the ZIP file in the same folder as your workshop files.
